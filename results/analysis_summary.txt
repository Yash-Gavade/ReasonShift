INTERPRETATION NOTE
Accuracy delta = transformed accuracy - original accuracy.
Correctness flip rate measures how often the correctness state changes between the original and transformed formulation.
Robust accuracy requires a question group to be answered correctly under all four formulations.
McNemar tests are exact paired tests. mcnemar_p_bh contains Benjamini-Hochberg multiple-testing corrected p-values.
Because the final benchmark contains only 30 question groups, statistical power is limited. Effect sizes, flip rates, and paired transitions should therefore be reported alongside significance tests.
